# Fimel Card 资源包

Minecraft Java 26.2 的 Fimel Cards 配套资源包，提供卡牌、牌桌家具、字体与音效。放入客户端 `resourcepacks` 并启用；更新后按 `F3+T`。

- [数据包项目与游玩说明](https://github.com/FimelStudio/fimelcard-dp)
- [下载](https://studiofimel.com/#/works/fimel-card)

## 兼容性

以下针对 Minecraft Java 26.2，Fabric 和钠的结论来自作者实测。

| 环境 | 兼容情况 |
| --- | --- |
| 原版 | 本包的目标环境，无需额外模组 |
| Fabric | 已实测兼容 |
| 钠（Sodium） | 已实测兼容 |
| Forge | 尚未验证 |
| OptiFine | 尚未验证 |

额外光影或覆盖字体、文字着色器的资源包组合需另行验证。

## 喵工坊家具来源说明
模型及相应纹理来自16bit制作组的[NyaaWork喵工坊家具](https://space.bilibili.com/2907002)。
本包仅将使用到的家具模型加至资源包中。资源归原作者所有。
