# Fimel Card 26.2 资源包 v1.0

适用于 Minecraft Java **26.2**，版本分支为 `26.2`，请与同版本 Fimel Cards 数据包配套使用。提供卡牌、牌桌家具、字体与音效；放入客户端 `resourcepacks` 并启用，更新后按 `F3+T`。

- [对应数据包与游玩说明](https://github.com/FimelStudio/fimelcard-dp/tree/26.2)
- [下载](https://studiofimel.com/#/works/fimel-card)

本发布分支不包含 `assets/minecraft/sounds` 和 `assets/minecraft/sounds.json`，因此不提供两首自定义唱片 `biwpy`、`departures`；卡牌及表情语音音效仍保留。

## 兼容性

Fabric、钠（Sodium）已由作者在 26.2 实测兼容；Forge、OptiFine 尚未验证。

## 家具来源

牌桌家具来自 16bit 制作组的 [NyaaWork 喵工坊](https://space.bilibili.com/2907002)，本包仅移入所用模型与纹理，资源归原作者所有。
