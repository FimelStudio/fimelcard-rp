# Fimel Card 资源包

Minecraft Java 26.2 的 Fimel Cards 配套资源包，放入客户端 `resourcepacks` 并启用；更新后按 `F3+T`。

- [数据包项目与游玩说明](https://github.com/FimelStudio/fimelcard-dp)
- [下载](https://studiofimel.com/#/works/fimel-card)

## 兼容性

以下针对 Minecraft Java 26.2，Fabric 和钠的结论来自作者实测。

| 环境         | 兼容情况                     |
| ------------ | ---------------------------- |
| 原版         | 本包的目标环境，无需额外模组 |
| Fabric       | 已实测兼容                   |
| 钠（Sodium） | 已实测兼容                   |
| Forge        | 应该兼容                     |
| OptiFine     | 应该兼容                     |

额外光影或覆盖字体、文字着色器的资源包组合需另行验证。

## 资源来源

牌桌家具及国际象棋棋子几何使用16bit制作组的[NyaaWork喵工坊资源](https://space.bilibili.com/2907002)，原始资源归原作者所有。
