# Fimel Card 1.21.11 资源包 v1.0

适用于 Minecraft Java **1.21.11**，版本分支为 `1.21.11`，请与同版本 Fimel Cards 数据包配套使用。提供卡牌、牌桌家具、字体与音效；放入客户端 `resourcepacks` 并启用，更新后按 `F3+T`。

- [对应数据包与游玩说明](https://github.com/FimelStudio/fimelcard-dp/tree/1.21.11)
- [下载](https://studiofimel.com/#/works/fimel-card)

本发布分支不包含 `assets/minecraft/sounds` 和 `assets/minecraft/sounds.json`，因此不提供两首自定义唱片 `biwpy`、`departures`；卡牌及表情语音音效仍保留。

## 兼容性

本分支已按目标版本适配并检查资源和文字着色器；实际显示及模组组合待游戏内测试。26.2 的 Fabric、钠实测结论不直接适用于本分支。

## 家具来源

牌桌家具来自 16bit 制作组的 [NyaaWork 喵工坊](https://space.bilibili.com/2907002)，本包仅移入所用模型与纹理，资源归原作者所有。
