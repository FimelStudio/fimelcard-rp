# Fimel Card 资源包

版本分支：`26.1-26.1.1-26.1.2`；配套数据包与资源包请使用同名分支。内容同步自 `main` 的 v1.1。

Minecraft Java 26.1 / 26.1.1 / 26.1.2 的 Fimel Card 配套资源包，放入客户端 `resourcepacks` 并启用；更新后按 `F3+T`。

[下载数据包和资源包](https://studiofimel.com/#/works/fimel-card) · [完整文档](https://github.com/FimelStudio/fimelcard-dp/blob/26.1-26.1.1-26.1.2/docs/README.md) · [数据包仓库](https://github.com/FimelStudio/fimelcard-dp/tree/26.1-26.1.1-26.1.2) · [资源包仓库](https://github.com/FimelStudio/fimelcard-rp/tree/26.1-26.1.1-26.1.2)

## 兼容性

本分支适配 Minecraft Java 26.1 / 26.1.1 / 26.1.2。Fabric 和钠的既有实测来自 26.2；本分支客户端表现仍需实测。

| 环境         | 兼容情况                     |
| ------------ | ---------------------------- |
| 原版         | 本包的目标环境，无需额外模组 |
| Fabric       | 26.2 已实测；本分支待客户端实测 |
| 钠（Sodium） | 26.2 已实测；本分支待客户端实测 |
| Forge        | 应该兼容                     |
| OptiFine     | 应该兼容                     |

额外光影或覆盖字体、文字着色器的资源包组合需另行验证。

## 资源来源

牌桌家具及国际象棋棋子几何使用16bit制作组的[NyaaWork喵工坊资源](https://space.bilibili.com/2907002)，原始资源归原作者所有。
